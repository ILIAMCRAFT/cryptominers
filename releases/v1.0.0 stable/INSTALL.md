# Installation Guide – CryptoMiners

## Requirements

Before installing CryptoMiners, make sure you have:

- Minecraft Java Edition 1.20.1
- Minecraft Forge 1.20.1
- Java 17 or newer

## Step 1 – Install Minecraft Forge

1. Download the Forge installer for Minecraft 1.20.1.
2. Run the installer.
3. Select **Install Client**.
4. Complete the installation.

## Step 2 – Download CryptoMiners

1. Visit the [CryptoMiners GitHub Releases](../../releases) page.
2. Download the latest compatible `.jar` file.
3. Make sure the downloaded version matches Minecraft 1.20.1 and Forge.

## Step 3 – Install the Mod

1. Press `Win + R`.
2. Enter `%appdata%\.minecraft`.
3. Open the `mods` folder.
4. If the folder does not exist, create it.
5. Copy the CryptoMiners `.jar` file into the folder.

## Step 4 – Launch Minecraft

1. Open the Minecraft Launcher.
2. Select the Forge 1.20.1 profile.
3. Launch the game.
4. Open the Mods menu and verify that CryptoMiners is installed.

## Troubleshooting

- **Mod does not appear:** Check that the JAR file is inside the correct `mods` folder.
- **Game crashes:** Verify Minecraft, Forge, Java, and mod version compatibility.
- **Missing dependencies:** Install any required dependencies listed on the project's release page.

## Support

If you encounter a problem, open an issue in the [GitHub Issues](../../issues) section.
